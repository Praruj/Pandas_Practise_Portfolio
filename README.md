#  Pandas Practice Portfolio

A collection of practical **Pandas projects and exercises** applied to real-world datasets. This repository demonstrates data analysis workflows including:

* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Data manipulation and transformation
* Aggregation and grouping
* Data visualization
* Extracting insights from diverse datasets

The goal of this portfolio is to showcase hands-on proficiency with the Pandas ecosystem and common data analysis techniques used in industry.

---

##  Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Praruj/Pandas_Practise_Portfolio.git
cd Pandas_Practise_Portfolio
```

### 2. Create a Virtual Environment

```bash
python -m venv .venv
```

### 3. Activate the Environment

**macOS / Linux**

```bash
source .venv/bin/activate
```

**Windows**

```bash
.venv\Scripts\activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Download Datasets

Download the datasets from the provided sources and place them inside the `data/` directory.

### 6. Launch Jupyter Notebook

```bash
jupyter notebook
```
